# McOptimize v1.0.0：麦当劳点餐优化 WorkBuddy 技能

根据预算、人数、必选商品和饮食偏好生成点餐建议，支持套餐组合、多人分配和三种目标排序。

## 安装包

- `mcd-optimize-skill.zip`：包含 `mcd-optimize/` 顶层目录的标准安装包。
- `mcd-optimize-skill-flat.zip`：`SKILL.md` 位于 ZIP 根目录的安装包。

两个安装包内容一致，按 WorkBuddy 导入方式选择对应目录结构。导入兼容性仍需实机验证。

## 验证情况

54 项离线测试全部通过；两个安装包均通过内容、CRC 和凭据检查。

当前使用模拟数据，已保留真实麦当劳 MCP 联调流程。真实计价、订单和 WorkBuddy 实机导入尚未验证；WorkBuddy 专项参赛仍需补充真实、脱敏的开发记录。
