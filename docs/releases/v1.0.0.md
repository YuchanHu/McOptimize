# McOptimize v1.0.0：麦当劳点餐优化 WorkBuddy 技能

由 GPT/Codex 辅助开发，主要用于 WorkBuddy。根据预算、人数、必选商品和饮食偏好生成点餐建议，支持套餐组合、多人分配和三种目标排序。

## 安装包

- `mcd-optimize-skill.zip`：包含 `mcd-optimize/` 顶层目录的标准安装包。
- `mcd-optimize-skill-flat.zip`：`SKILL.md` 位于 ZIP 根目录的安装包。

两个安装包内容一致，按 WorkBuddy 导入方式选择对应目录结构。作者的安装目录 Skill 已在 WorkBuddy 成功加载并执行；具体导入包名、布局和客户端版本未在记录中注明。

## 验证情况

54 项离线测试全部通过；两个安装包均通过内容、CRC 和凭据检查。

2026-10-09 补充真实 WorkBuddy 与麦当劳 MCP 联调记录：

- Skill 加载、安装目录资料读取、本地 Node.js v22.22.2 脚本执行，以及官方门店、菜单、套餐查询和价格回填已取得记录。
- 两人 70 元预算：推荐组合官方核价 **65.80 元**，最低金额组合 **43.30 元**，均仅对应当时门店与配置。
- 100 人 100 元案例：采购组合官方核价 **100.00 元**，备选 **290.00 元**；此场景由 WorkBuddy 对话推理完成，超出本地求解器 8 人上限，不代表百人引擎验收或实际份数/饱腹保证。
- **作者确认已在 WorkBuddy 完整验证并成功下单**；两份导出没有 `create-order`、`query-order` 或支付回执，下单结果按作者实测反馈记录，不推断支付完成。

完整脱敏记录：[WorkBuddy 使用记录](https://github.com/YuchanHu/McOptimize/blob/main/docs/workbuddy-usage-records.md)。证据和边界：[实测汇总](https://github.com/YuchanHu/McOptimize/blob/main/docs/workbuddy-validation.md)。这些记录只证明在 WorkBuddy 中使用与联调，不作为 WorkBuddy 开发作品或专项开发材料。

两人会话实际发起 16 次计价调用，13 次成功、3 次参数校验失败，不能将原回复“12 次全部成功”当作完整统计；Agent 整轮 12 次调用预算仍待改进。真实营养、外送、有券核销、订单状态及异常恢复尚未覆盖。
