# McOptimize v1.0.0 · 麦麦最优解

由 GPT/Codex 辅助开发，主要用于 WorkBuddy。根据整单预算、个人偏好和营养要求生成点餐组合，经麦当劳官方 MCP 核价后展示推荐与每人份数，明确确认后创建订单。

## 已完成的功能

- 预算与必选条件校验、套餐子项分配、最低金额/丰富优先/营养优先三目标推荐。
- 真实门店、菜单、套餐与营养查询，官方价格回填和改餐重新核价。
- 完整摘要确认、一次建单、未知订单状态保护和官方支付流程。
- 54 项自动化测试、白名单 ZIP 打包、CRC32/SHA256 与凭据检查。

## WorkBuddy 真实验证

已贯通 Skill 加载、Node 脚本执行、实时数据查询、组合搜索、核价、分配、重新确认与成功建单。

| 场景 | 实测结果 |
|---|---|
| 三人预算 90 元，各有口味与热量约束 | 三种方案 **54.00 / 63.90 / 65.00 元**；C 分别为 **369 / 595 / 325 kcal**；最终确认后一次成功创建 **54 元**外带订单 |
| 两人预算 70 元，套餐与去洋葱偏好 | 推荐 **65.80 元**，最低金额 **43.30 元**，完成官方核价与价格回填 |
| 百人预算 100 元的规则迭代 | 官方核价 **100.00 元**采购组合；由 WorkBuddy 对话推理处理大规模分配 |

三人订单回执为“待支付”；建单与支付分开，由用户在官方页面完成付款。真实营养、价格与订单回执来自 2026-10-09 的到店会话，新增记录于 2026-10-10 归档。

## 安装包

- `mcd-optimize-skill.zip`：包含 `mcd-optimize/` 顶层目录。
- `mcd-optimize-skill-flat.zip`：`SKILL.md` 位于 ZIP 根目录。

按客户端导入入口选择对应布局，或解压后添加技能目录。需要 Node.js 20+ 和已配置的官方 MCP 服务。

本地求解器支持 1–8 人，推荐针对已搜索候选；外送、有券核销及支付后查询的实测覆盖说明见验证汇总。两包保留首次发布快照，最新验证文档在线提供。
